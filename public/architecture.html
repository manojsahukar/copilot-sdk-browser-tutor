Threats and controls

ThreatControl in this app
Someone calls the Lambda URL directly, skipping CloudFrontSecret X-Origin-Verify header checked on every request except /healthz; 403 otherwise
Prompt injection in a page, header or tool resultTool output fenced as untrusted data; tools are an exact allowlist with no shell, file or fetch access
The model tries to run code in your browserrun_demo takes only a fixed name; the page runs its own static code
Malicious HTML in a model reply (XSS)Markdown sanitised with DOMPurify; CSP allows scripts only from the site itself
Cross-site request forgerySameSite=Lax cookie plus an Origin check on every state-changing request in the main app
Stolen or replayed sessionSealed AES-256-GCM cookie, HttpOnly and Secure, 7-day cap, short-lived access token refreshed on the server
Leaked secrets in config or logsSecrets in one Secrets Manager secret, not env vars; tokens and keys scrubbed from logs
One user's chat seen by anotherOne Copilot session per signed-in user; no shared server credential
Runaway cost or abuse30 turns per hour per session, reserved concurrency of 5, free models by default on OpenRouter
